# Documentation

Use this documentation to build and operate an app with `@eliware/discord`.

## Start here

1. Read [Usage](usage.md) to install the package and start a client.
2. Read [Configuration](configuration.md) to set credentials, folders, intents, and handlers.
3. Read [Commands](commands.md), [Events](events.md), and [Localization](localization.md) to add app behavior.
4. Read [Lifecycle](lifecycle.md) to stop the client safely.

## Reference

- [API](api.md) lists public functions, options, and types.
- [Troubleshooting](troubleshooting.md) explains common setup and runtime problems.
- [Migration to version 13](migration-v13.md) describes breaking changes from earlier versions.

## Example

The `examples/` folder contains a runnable basic app. The root `README.md` gives a short project
overview and links to the package and support pages.
